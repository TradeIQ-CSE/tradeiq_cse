# ADR 0007: Seed dataset — validated 2017–2025 window

- **Status:** Accepted
- **Date:** 2026-08-11
- **Source:** IMPLEMENTATION_PLAN.md §0.1 (D7) · Linear TIQ-41

## Context

Development, demos, and UAT need realistic market data; SRS fixes the validated
backtest window at 2017–2025 (SRS 2.5) and requires first-run usability (3.5.2).

## Decision

Seed `market_data` from a versioned `cse-dataset` release (artifact contract
v1): **2017–2025 OHLCV + ASPI, S&P SL20, SL20TRI and ASTRI index history +
trading calendar**. Seeding runs as the one-shot `market-data-seed` compose job
right after migrations, with `python -m data_ingestion.release_import`. It is
idempotent, and falls back to a small bundled sample when no release is
configured.

Corporate actions and listings/delistings were part of the original decision,
but contract v1 doesn't carry them, so they aren't seeded yet.

History: TIQ-39 / PR #20 built the first seed from a bundle of cse-dataset
files; TIQ-49 replaced it with the release importer on 2026-09-12.

## Consequences

- A fresh `docker compose up` is immediately queryable — FE can build against
  real-shaped data from day one.
- Backtests, charts, and the market overview all operate on the same validated
  window the SRS guarantees.
- Eras beyond the seed come later via the pipeline's historical-backfill command
  (SRS 3.1.4.1), not by widening the seed.
